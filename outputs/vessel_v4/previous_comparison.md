# v2 / v3 血管分割误差诊断

比较只使用提供的训练标签与已保存的原生尺寸概率，没有运行 GPU、重新训练或读取测试真值。两版公平对齐的子集为 fold 0：ID 1、10、15、19；两者都使用已选定的 TTA 预测。

## 先读指标定义

所有重合判断都在原生 584×565 像素网格上进行，阈值规则为 `p >= t`，不做 512 缩放、膨胀或距离容差。表中指标均先逐图计算再取平均，JSON 同时保存合并像素计数与 micro/pooled 指标。

- **EDT≤2 像素召回**：真实血管像素中，到最近背景像素的欧氏距离不超过 2 像素者被预测覆盖的比例。它包含粗血管的边界带，不能单独叫作纯细血管召回。
- **全骨架召回**：对真实标签使用 Zhang 骨架化后，骨架像素被预测覆盖的比例。
- **薄骨架召回**：仅在真实骨架且 EDT≤2 的点上计算覆盖率，是更针对细小标注分支的代理。EDT>2 的骨架另报粗骨架召回。
- 这些是二值标注的数字几何代理，受像素化、标签厚度和骨架化影响；没有物理标定，**不是解剖血管直径，也不是临床测量**。严格骨架覆盖还会受一像素位置偏移影响。

## 测量支持的结论与尚未证明的原因

- 在共同4图、TTA、固定0.50下，v3相对v2的Dice差为-0.008069，Precision差为-0.005160，Recall差为-0.009386。
- 相同阈值下，v3薄骨架召回相对v2变化-3.30个百分点；各自已选阈值下仍变化-1.47个百分点。
- 降低到v3已选阈值后，其总体召回已略高于v2，但Precision和Dice仍更低；本次差距不能仅用过高的二值阈值解释，同时存在误检与局部细结构覆盖不足的问题。
- 各自已选阈值下，v3的EDT≤2像素召回略高，但薄骨架召回较低。这两个区域并不等价，证明不能把粗血管边界带混同为细血管中心线。

可能原因只能作为后续消融假设：两版同时改变了网络结构、预训练初始化、归一化方式、学习率、训练时长和模型融合，现有比较不能把差距归因于某一个因素。尤其不能据此断言“预训练无效”或“下采样必然导致这些漏检”。v4 应在固定划分与指标下逐项检验细节保留、训练充分程度和损失/采样修改，同时监控误检与整体 Dice，避免用更粗的预测换取单一召回指标上升。

## 可复现与范围

运行命令：`..\..\work\.venv-gpu\Scripts\python.exe diagnose_previous.py`（在本目录执行）。脚本只读取旧版本与提供的训练集，只向指定的新输出目录写 JSON/Markdown。没有改动 v1/v2/v3、下载图像数据或模型权重，也没有 GPU 推理。

骨架实现固定为 `skimage.morphology.skeletonize(..., method='zhang')`；欧氏距离采用 `scipy.ndimage.distance_transform_edt`，单位为原生像素。环境版本与输入 SHA-256 均记录在 JSON。

本报告所有结论均限定于可见训练标签与既有折外预测；未评价隐藏测试标签、官方 512 转换指标或 Kaggle 分数。
