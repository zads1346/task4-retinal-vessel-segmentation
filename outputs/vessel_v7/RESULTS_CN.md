# v7.0.0 训练说明与结果

全部新增文件保存在 D:\KaggleProjects\2026task4\outputs\vessel_v7。旧版本 v1–v6 保留。只使用题目提供的 20 张训练图像及标签，另对提供的 20 张无标签测试图像做推理；没有引入其他训练集或外部预训练权重。

## 实验方法

方案 1：对每一折已有 v6 LoRA 更新做权重空间缩放，Wβ = Wv4 + β(Wv6 − Wv4)，比较 β=0、0.25、0.5、0.75、1 的完整五折 OOF。β=0 和 β=1 复用核验过的已有留出预测；中间 3 组实际重新推理。这不是预测概率混合。

方案 2：从对应折的 v4 U-Net 重新初始化解码器 Conv-LoRA，rank=4、alpha=4，训练参数 54,720，冻结参数 4,416,673。分别以 1e-5 和 3e-5 两个峰值学习率运行完整五折，共 10 次训练；每折完成 300 batch，batch size=8，原生 256×256 patch，AdamW、weight decay=1e-4、30 batch warmup、余弦退火、AMP、梯度裁剪 1。保留 v4 的 RGB 输入、细血管采样、增强和损失，分折种子 2026，采样种子 12026+fold。

每折第 0 步及每 25 batch 用 D4 八视角推理验证；固定阈值 0.5 选择检查点，改善需超过 1e-5，否则保留较早检查点。第 0 步被选中时等价于该折继续使用 v4，不能算作微调提升。以固定阈值 0.5 比较完整五折候选；1e-5 以内的平局优先较简单方案。最后只对选中候选在 0.40–0.60、步长 0.02 上选择一个全局阈值。
